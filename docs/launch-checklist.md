# Checklist sebelum menerima peserta dan pembayaran

Status: belum siap berjualan.

- [ ] Tetapkan instruktur, informasi pengelola, kontak, harga, masa akses dan kebijakan refund.
- [ ] Produksi dan periksa seluruh materi orisinal atau memperoleh lisensi komersial tertulis.
- [ ] Bangun sistem akun dengan verifikasi email, reset password, otorisasi server dan rate limiting.
- [ ] Sediakan database, migrations, backup dan pengujian pemulihan.
- [ ] Bangun katalog, checkout, order, enrollment dan dashboard peserta serta admin.
- [ ] Integrasikan gateway pembayaran resmi, webhook tervalidasi, idempotensi dan rekonsiliasi.
- [ ] Integrasikan video berizin, akses sementara, caption, transkrip dan unduhan terlindungi.
- [ ] Sediakan dukungan, kebijakan privasi, syarat, hak pengguna dan peninjauan kepatuhan.
- [ ] Jalankan uji end-to-end di sandbox, mobile, aksesibilitas, keamanan dan operasi.
- [ ] Lakukan pilot dan verifikasi seluruh alur sebelum promosi dan transaksi produksi.
- [ ] Lengkapi Figma Design editable seluruh halaman dan pemetaan komponen kode; draft landing awal sudah ada.
- [ ] Setelah konten dan legal siap, siapkan URL canonical, sitemap, Search Console dan ubah arahan noindex.
